FiQA 上的多向量精确重排 · 磁盘布局与真实 Qdrant 对照
2026-11-22 · Windows 单机实测

结论
在完整 FiQA 上，能复现的优势集中在 Qdrant 首次从磁盘访问、且候选由均值向量召回的场景。把同一库改为语义布局，P95 从 50.46 ms 降到 42.41 ms，降幅 16.0%，按查询配对的 95% 区间为 8.6%–23.7%。BM25 候选的首访降幅只有 2.3%，区间跨零；两种候选合并后降幅为 2.6%，区间同样跨零。两次新副本试验中，128 次混合查询引起的 D 盘读取从约 599–600 MiB 降至约 544 MiB，约少 9%。
完整回放之后，Qdrant 自身用两种布局的 P95 基本相同。独立原型的 GPU 直接读取路径明显慢于热态 Qdrant。对于同一首次访问查询子集，本地原型与 Qdrant 的 P95 差异在两种候选上均未取得方向稳定的优势。现有数据支持把算法定位为磁盘多向量索引的离线布局优化。面向通用检索用户，优先考虑接入已有引擎；发布时应注明首次访问条件、候选生成器和静态快照的 ID 映射要求。

三　首次访问与原序/布局对照
为每种布局创建两份从未用于查询的本地 NTFS 副本，使用 robocopy /J 无缓冲复制。每个副本启动独立的 Qdrant 进程，启用 no_populate，第一遍查询前只检查集合状态。每个副本依相同随机次序运行 64 个查询 × 两种候选，共 128 次，然后立即按同序再跑一遍。两轮交替哪个布局先测。下表汇总两轮的 P95，并附按查询配对自助重采样的区间。

四　物理顺序核验
仅按语义顺序导入、保留原数值 ID 的 Qdrant 集合，在优化器整理后有 57,638 个物理位置符合原始顺序，只有 3 个位置碰巧符合目标顺序。首次探索回放因此不参与正式速度比较。
正式集合将数值存储 ID 设为目标布局位置。向 Qdrant 传入候选时映射成存储 ID，取结果时恢复原文档行号。原始顺序、映射后 FP16 与映射后 FP32 均逐篇审计，全部 57,638 个位置的内容符合各自目标。审计按实际物理地址排序并计算全文档哈希，FP32 额外验证所有数值均来自原 FP16。每个集合含一个有数据的段和一个空段；语料有 57,594 种不同向量内容，完全相同的记录从内容本身无法区分。
本文的物理位置指向量记录在 Qdrant 各块文件内的存储次序。审计能够验证文件偏移和内容，无法观测 NTFS 簇分配及 SSD 内部 NAND 地址。

五　实验边界与复核
完整 FiQA 为 57,638 篇文档、7,314,136 个 96 维 FP16 token，文档向量载荷约 1.31 GiB。固定哈希划分 648 个原始查询，324 个校准查询拟合热门层；另 160 个评测、8 个预热，其余未参加计时。语义层内沿用第二轮版本。上游分别用均值向量相似度和英文词项 BM25（k1=1.2、b=0.75）产生固定名单。布局只看均值召回的校准流。BM25 文本按原文档 ID 对齐。候选生成、建库和 FP64 参考分计算均在计时外。
两种召回的每 200 篇候选平均只有 17.0 篇重合。所有实验衡量固定候选的点积 MaxSim 重排，没有测全库召回质量或原始文本编码。
硬件为 Intel Core i5-12400、15.7 GiB 物理内存、RTX 3060 12 GB、D 盘 Great Wall GW3000 1TB NVMe、Windows。服务端 Qdrant 1.20.2 使用 96 维 Dot、max_sim、FP16 或 FP32、on_disk=true、HNSW m=0、无向量量化、1 个分片。客户端通过环回 HTTP 外部候选 has_id 过滤，exact=true。Qdrant 使用其原生 CPU 评分和操作系统文件缓存。
本地算法仍用上一轮公开 Ranker。GPU 路径在四个线程上做 Windows 非缓冲读，按 4 KiB 对齐并合并相邻区间，FP64 精算；热门向量载荷 117,375,552 字节，按 10% 索引数据预算扣除元数据。CPU 控制组使用同一算法、两条运算线程、普通文件读取和操作系统页缓存，关闭显式热门缓存。各方法返回相同语义的逻辑 ID；Qdrant 耗时含返回 ID 映射，候选 ID 转换和请求体序列化预先完成。Qdrant 的页缓存没有 RAM 配额，实验没有声称相同进程 RSS 或相同精算内核。
正降幅表示语义布局更快，负降幅表示更慢。P95 与 P50 为请求耗时分位数；区间为按查询 ID 配对、有放回重采样 3,000 次，同一查询的多轮一起抽。首次访问各布局仅有两次独立进程启动，区间反映查询样本波动，无法覆盖跨机器、跨日期及所有缓存状态的不确定性。单机、单并发、单编码器及固定候选数构成本轮适用范围。
